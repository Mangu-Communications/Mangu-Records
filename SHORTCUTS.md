# Hathor Forge — Shortcuts

Spacebar is sacred: it toggles playback on every panel unless a text / lyric / prompt field is focused.

| Key | Scope | Action |
| --- | --- | --- |
| Space | Global, except text fields | Play / stop |
| Shift+Space | Global, except text fields | Stop and return to beat 0 |
| 1 | Global, except text fields | Score |
| 2 | Global, except text fields | Mix |
| 3 | Global, except text fields | Sound |
| 4 | Global, except text fields | Voice |
| 5 | Global, except text fields | Compose |
| L | Global, except text fields | Loop |
| C | Global, except text fields | Metronome |
| A W S E D F T G Y H U J K | Sound view | Piano (C4–C5) |
| ⌘Z / Ctrl+Z | Global | Undo |
| ⌘⇧Z / Ctrl+Shift+Z | Global | Redo |
| ? | Global, except text fields | Shortcuts overlay |
| Esc | Dialogs | Close |
| Click piano roll | Score | Add 16th (Shift = 1 beat); click note to delete |
| Click drum pad | Score / inspector | Toggle hit |
